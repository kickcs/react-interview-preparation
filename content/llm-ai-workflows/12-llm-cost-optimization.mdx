<AnswerGroup>
<Answer lang="en">

LLM costs are driven by **token consumption**: input tokens (prompt) + output tokens (completion), priced per million. In a multi-turn application, input tokens grow with conversation history — a 10-turn conversation might pass 5,000 tokens of history on every request. At $3/MTok for Claude Sonnet, that's $0.015 per request, which becomes $150 for 10,000 daily users. Cost optimization requires a layered approach.

**Prompt caching** (Anthropic's and OpenAI's) is the highest-leverage optimization for applications with a large static prefix (system prompt, document corpus, few-shot examples). Anthropic caches prompt prefixes when marked with `cache_control: { type: "ephemeral" }` — cached tokens cost 10% of normal input price after the initial cache write. For a 10,000-token system prompt sent on every request, prompt caching saves ~90% of those input costs. The cache TTL is 5 minutes (Anthropic) — it resets on each use within that window, so a chatbot with continuous traffic keeps the cache warm.

**Model routing** is the second lever: use the smallest model that can do the job adequately. For classification, extraction, and structured output from short inputs, `claude-3-5-haiku` is 10-20x cheaper than Sonnet with comparable quality. Route based on task complexity: a lightweight classifier can route "simple" queries to Haiku and "complex" queries to Sonnet. **Semantic caching** stores (query embedding → LLM response) pairs and returns cached responses for semantically similar queries — Redis or Qdrant can serve as the cache store. **Batching** (OpenAI Batch API, Anthropic Batch Messages API) processes requests asynchronously at 50% off — useful for offline enrichment, bulk summarization, and eval pipelines.

Стоимость LLM определяется **потреблением токенов**: input токены (промпт) + output токены (completion), цена за миллион. В multi-turn приложении input токены растут вместе с историей диалога — беседа из 10 ходов может передавать 5 000 токенов истории в каждом запросе. При $3/MTok для Claude Sonnet — $0.015 за запрос, что превращается в $150 для 10 000 ежедневных пользователей. Оптимизация стоимости требует многоуровневого подхода.

**Prompt caching** (у Anthropic и OpenAI) — оптимизация с наибольшим рычагом для приложений с большим статичным префиксом (system prompt, корпус документов, few-shot примеры). Anthropic кеширует префиксы промпта, отмеченные `cache_control: { type: "ephemeral" }` — кешированные токены стоят 10% от обычной цены после первоначальной записи. Для system prompt из 10 000 токенов, отправляемого при каждом запросе, prompt caching экономит ~90% этих input затрат. TTL кеша — 5 минут (Anthropic), сбрасывается при каждом использовании в этом окне, поэтому чатбот с непрерывным трафиком держит кеш тёплым.

**Model routing** — второй рычаг: используй наименьшую модель, достаточно справляющуюся с задачей. Для классификации, извлечения и structured output на коротких вводах `claude-3-5-haiku` в 10-20 раз дешевле Sonnet при сопоставимом качестве. Роутинг по сложности задачи: лёгкий классификатор отправляет "простые" запросы в Haiku, "сложные" — в Sonnet. **Semantic caching** хранит пары (embedding запроса → ответ LLM) и возвращает кешированные ответы на семантически похожие запросы. **Batching** (OpenAI Batch API, Anthropic Batch Messages API) обрабатывает запросы асинхронно со скидкой 50% — полезно для офлайн-обогащения, массовой суммаризации и eval pipelines.

```typescript
// LLM cost optimization: prompt caching + model routing + semantic cache

import Anthropic from "@anthropic-ai/sdk";
import { Redis } from "@upstash/redis";
import OpenAI from "openai";

const anthropic = new Anthropic();
const openai = new OpenAI();
const redis = new Redis({ url: process.env.UPSTASH_REDIS_URL!, token: process.env.UPSTASH_REDIS_TOKEN! });

// --- Prompt Caching (Anthropic) ---
// Статичный контент помечается cache_control
const LARGE_SYSTEM_PROMPT = `You are an expert financial analyst...`; // ~5000 токенов

async function analyzeWithCaching(userQuery: string): Promise<string> {
  const response = await anthropic.messages.create({
    model: "claude-3-5-sonnet-20241022",
    max_tokens: 1024,
    system: [
      {
        type: "text",
        text: LARGE_SYSTEM_PROMPT,
        // Помечаем статичный prefix для кеширования
        // После первого вызова этот блок стоит 10% цены
        cache_control: { type: "ephemeral" } as { type: "ephemeral" },
      },
    ] as Anthropic.TextBlockParam[],
    messages: [{ role: "user", content: userQuery }],
  });

  // Логируем метрики кеша
  const usage = response.usage as typeof response.usage & {
    cache_creation_input_tokens?: number;
    cache_read_input_tokens?: number;
  };
  console.log({
    inputTokens: usage.input_tokens,
    cacheWrite: usage.cache_creation_input_tokens ?? 0,
    cacheRead: usage.cache_read_input_tokens ?? 0,
    outputTokens: usage.output_tokens,
    // Экономия: cache_read_input_tokens * 0.9 * price_per_token
  });

  return (response.content[0] as { text: string }).text;
}

// --- Model Router ---
type TaskComplexity = "simple" | "moderate" | "complex";

function classifyComplexity(prompt: string): TaskComplexity {
  const wordCount = prompt.split(" ").length;
  const hasMultiStep = /\b(and then|after that|finally|compare|analyze)\b/i.test(prompt);
  const hasCode = prompt.includes("```") || prompt.includes("function");

  if (wordCount < 20 && !hasMultiStep && !hasCode) return "simple";
  if (wordCount > 100 || hasCode) return "complex";
  return "moderate";
}

const MODEL_BY_COMPLEXITY: Record<TaskComplexity, string> = {
  simple: "claude-3-5-haiku-20241022",    // ~$0.08/MTok input — 20x cheaper
  moderate: "claude-3-5-haiku-20241022",
  complex: "claude-3-5-sonnet-20241022",  // ~$3/MTok input
};

async function routedLLMCall(prompt: string): Promise<string> {
  const complexity = classifyComplexity(prompt);
  const model = MODEL_BY_COMPLEXITY[complexity];

  const response = await anthropic.messages.create({
    model,
    max_tokens: 512,
    messages: [{ role: "user", content: prompt }],
  });

  return (response.content[0] as { text: string }).text;
}

// --- Semantic Cache ---
const CACHE_SIMILARITY_THRESHOLD = 0.92; // только очень близкие запросы

async function semanticCachedCall(prompt: string): Promise<string> {
  // Embed query
  const embRes = await openai.embeddings.create({
    model: "text-embedding-3-small", input: prompt,
  });
  const embedding = embRes.data[0].embedding;

  // Поиск в кеше (pgvector или Qdrant в production; Redis для простого примера)
  const cacheKey = `semcache:${Buffer.from(JSON.stringify(embedding)).toString("base64").slice(0, 32)}`;
  const cached = await redis.get<string>(cacheKey);
  if (cached) {
    console.log("Semantic cache HIT");
    return cached;
  }

  // Cache MISS — вызов LLM
  const result = await routedLLMCall(prompt);

  // Сохраняем в кеш (TTL 1 час)
  await redis.setex(cacheKey, 3600, result);

  return result;
}

// --- Batch processing (Anthropic Batch API) ---
async function batchSummarize(documents: string[]): Promise<string[]> {
  const batchRequests = documents.map((doc, i) => ({
    custom_id: `doc-${i}`,
    params: {
      model: "claude-3-5-haiku-20241022" as const,
      max_tokens: 256,
      messages: [{ role: "user" as const, content: `Summarize in 2 sentences: ${doc}` }],
    },
  }));

  const batch = await anthropic.messages.batches.create({ requests: batchRequests });
  console.log(`Batch ${batch.id} created — 50% cheaper, processes async`);

  // Poll until complete (in production: webhook or scheduled job)
  let done = false;
  while (!done) {
    await new Promise((r) => setTimeout(r, 5000));
    const status = await anthropic.messages.batches.retrieve(batch.id);
    done = status.processing_status === "ended";
  }

  const results: string[] = [];
  for await (const result of await anthropic.messages.batches.results(batch.id)) {
    if (result.result.type === "succeeded") {
      results.push((result.result.message.content[0] as { text: string }).text);
    }
  }
  return results;
}
